# UNO Telegram Bot

Учебный Telegram-бот для игры в UNO в групповых чатах. Для каждого чата хранится отдельная игровая сессия; игроки выбирают действия и карты через клавиатуру бота.

## Возможности

- Создание игры, присоединение игроков и запуск партии в групповом чате.
- Карты разных цветов, смена направления, пропуск хода и дополнительные карты.
- Выбор карты и цвета через кнопки клавиатуры.
- Объявление победителя и подсчёт штрафных баллов остальных игроков.
- Команды помощи, просмотра игроков и завершения партии.

Это учебная реализация: её правила могут отличаться от официальных правил UNO. Состояние игр хранится в памяти и теряется при перезапуске процесса.

## Локальный запуск

Нужны Python 3.12, доступ к Telegram и токен бота от [BotFather](https://t.me/BotFather).

```bash
git clone https://github.com/lioiioiioil/UnoBot.git
cd UnoBot
python3.12 -m venv .venv
source .venv/bin/activate
python -m pip install -r src/requirements.txt
export BOT_TOKEN='replace_with_token_from_BotFather'
python src/run.py
```

Замените значение `BOT_TOKEN` своим токеном. Код читает его из окружения; при пустой или отсутствующей переменной запуск завершается с понятным сообщением. Точка входа — `src/run.py`, зависимости перечислены в `src/requirements.txt`.

## Запуск в Docker

Из корня репозитория:

```bash
cp .env.example .env
```

Откройте `.env` в редакторе и замените значение `BOT_TOKEN` своим токеном, затем:

```bash
docker build -t uno-bot .
docker run --rm --name uno-bot --env-file .env uno-bot
```

Файл `.env` исключён из Git и контекста сборки Docker. Само приложение не загружает `.env`: в этом варианте переменную передаёт Docker через `--env-file`.

Бот использует long polling, поэтому публиковать входящий порт контейнера не нужно. Для одного токена запускайте один экземпляр бота. При локальном запуске остановите контейнер, использующий тот же токен, и наоборот.

## Как начать игру

1. Добавьте бота в Telegram-группу. У игроков должны быть заданы Telegram-имена пользователя (`@username`).
2. Отправьте `/start_game`, чтобы создать игру.
3. Игроки нажимают «Присоединиться» или отправляют `/join`.
4. После присоединения игроков нажмите «Начать игру» или отправьте `/play`.
5. Выбирайте карту, цвет и другие действия через клавиатуру бота. Для остановки партии используйте `/end_game`.

Повторный `/start_game` не заменяет команду `/play`: эта команда создаёт новую игру, если партия ещё не запущена.

## Команды

| Команда | Действие |
| --- | --- |
| `/start` | Краткое приветствие |
| `/start_game` | Создать игру в текущем чате |
| `/join` | Присоединиться к игре |
| `/play` | Начать партию |
| `/stats` | Показать игроков текущей игры |
| `/end_game` | Завершить партию |
| `/help` | Справка по командам |
| `/help_game` | Справка по правилам реализации |
| `/clear` | Убрать клавиатуру |
| `/admin` | Показать авторов проекта |

## Структура проекта

- `src/run.py` — запуск long polling.
- `src/unoBot.py` — обработчики Telegram-сообщений и отправка ответов.
- `src/logic.py` — карты, игроки и игровые сессии.
- `src/bot_auxilliary.py`, `src/queue_stream.py`, `src/sharedVars.py` — обработка команд и очередь сообщений.
- `src/cards.txt` — описание карт и идентификаторы стикеров.
- `notes/` — заметки и материалы разработки.
- `result/` — скриншоты игры.

## Проверка синтаксиса

```bash
python -m compileall -q src
```

Эта команда не запускает бота и не обращается к Telegram. Проверять отправку сообщений и полную партию нужно отдельно с настроенным токеном.

Изолированные проверки конфигурации запускаются без зависимостей приложения:

```bash
python -m unittest discover -s tests -v
```

Они подменяют Telegram-библиотеку и импорты игровых модулей: проверяют пустой токен, отказ валидатора и порядок проверки до запуска фоновой обработки. Это не проверка реального токена или Telegram API.
